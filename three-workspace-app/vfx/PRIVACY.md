# Privacy policy

Effekseer AI is a local developer tool.

- It does not include telemetry, analytics, advertising, user accounts, or a network client.
- The CLI and MCP server operate on files that the user explicitly opens, creates, saves, exports, or imports.
- The MCP server communicates through standard input and output with the locally configured client; it does not expose a network port.
- Effect files and imported image resources remain on the user's machine unless the user independently shares them.

Do not commit private effect files, textures, models, project folders, credentials, or machine-specific configuration to this repository.
