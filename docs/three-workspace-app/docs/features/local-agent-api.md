# 1.6.1 / 1.6.3 — Python CLI, API và MCP local

**Implementation hiện tại:** `agent/unified_cli.py` là client Python chuẩn; `agent/unified_mcp.py` là MCP stdio stateless 2026-07-28. Cả hai gọi loopback Studio broker, không ghi project độc lập. MCP công bố `bbs_unified_command` với 17 command, gồm `scene.render`, `film.export`, `job.get` và `job.cancel`. CLI có `scene render PROJECT_ID --frame N --camera-node-id ID --output-dir EXISTING_FOLDER`; client giữ đường dẫn cục bộ, broker chỉ nhận UUID opaque, rồi tải artifact theo job/file ID và kiểm SHA/size trước khi ghi vào thư mục con `render-<jobId>`. MCP render bắt đầu job trước; `job.get` tiếp tục polling, khi thành công mới ghi artifact vào thư mục con đã chọn. MCP process giữ path tạm trong bộ nhớ; nếu process khởi động lại, gọi lại command cùng requestId và output path để gắn lại đích.

CLI còn hỗ trợ `motion place PROJECT_ID MOTION_ID CHARACTER_ID --frame-start N --source-start SEC [--source-length SEC] --speed X --loop --reverse`; broker yêu cầu FBX Motion có clip index và Character cùng skeleton fingerprint/đơn vị, rồi đặt source range lên Topview timeline với shared binding/history. Source-time evaluator giữ trim/reverse; speed/loop dùng playback fields của Topview. Root-motion/alignment và Retarget/bake khác rig chưa thực hiện. CLI nhận `scene apply PROJECT_ID operations.json` tối đa 64 MiB; batch node ops hoặc một `document.replace` dùng shared revision. `character add`/`prop add` nhận transform và `--parent-node-id`; CLI lưu session V9.12 tối đa 12 MiB nhưng chưa chạy solver/bake/export. Upload/import, relink, converter jobs và keyframe editing chưa được công bố qua MCP. Node host giữ quyền ghi; CLI ánh xạ validation/conflict/capability sang exit code 2/3/4, giữ revision snapshot, truy vấn requestId sau timeout rồi retry cùng payload có giới hạn. MCP host cần duyệt lời gọi có ghi file.

CLI chỉnh clip: `motion binding set PROJECT binding.json --expected-revision N [--clip-patch patch.json]`; mỗi JSON tối đa 1 MiB và phải là object. Payload đi nguyên qua broker `motion.binding.set`; root/alignment/fade chưa hỗ trợ bị từ chối. FrameEnd inclusive; nếu bỏ frameEnd thì dời frameStart giữ span cũ. CLI và MCP bắt buộc revision của snapshot đang sửa; không tự lấy revision mới nhất cho binding cũ. MCP gọi cùng command với expectedRevision và requestId.

CLI có `film convert-model SOURCE.fbx|SOURCE.glb --output-dir EXISTING_FOLDER [--unit-meters N]` dùng Blender local tạo BOBJ/profile và PNG tùy chọn; FBX bắt buộc unit. `film export MANIFEST --output-dir EXISTING_FOLDER` chạy offline worker Java 17 từ manifest typed. Project export dùng `film project-export PROJECT_ID --character-id ID --sequence-id ID --start-frame N --end-frame N --viewport-aspect R --film-name NAME --output-dir EXISTING_FOLDER`; CLI gọi `film.export`, poll/cancel job và tải ZIP đã kiểm size/SHA vào thư mục con mới. MCP `film.export` nhận cùng project sampling args và `outputDirectory.path` ở client; path được bỏ khỏi broker command, còn `job.get` ghi ZIP đã xác minh vào `film-<jobId>`. Studio có panel Film export dùng chung job/file routes, nhưng browser job interaction, full project conversion và live MCP host chưa được smoke. Chi tiết converter ở [local conversion](local-conversion-cli.md) và package ở [BBS Film export](bbs-film-export.md).

## Mục tiêu / reuse

CLI nhập FBX: `asset import PROJECT character.fbx --format fbx --unit-meters 0.01`. Unit bắt buộc, finite/positive, được kiểm trước upload kể cả auto-detect. FBX có mesh tạo model Asset kèm Motion nên sau import có thể thêm Character/Prop và đặt motion cùng source profile; không suy cm từ tên file. Batch có glTF vẫn tuân thủ unit=1 của glTF. MCP upload/relink chưa được công bố.

Giữ CLI0.1.8 project/document/node/pose/assets/inspect/evaluate/render/doctor, JSON errors và exit behavior trên project Topview cũ. Để chạy MCP local, khởi động Studio host trước rồi cấu hình MCP client chạy `python -m agent.unified_mcp` với working directory là `three-workspace-app`; `BBS_APP_URL` mặc định `http://127.0.0.1:3002`. Server chỉ phục vụ stdio MCP `2026-07-28`; client 2025-11-25 trở về trước chưa hỗ trợ.

CLI exit0 thành công,2invalid arguments/validation,3revision conflict,4missing capability/runtime,1IO/internal; stderr diagnostic không chứa token/asset bytes, MCP stdout chỉ JSON-RPC messages.

## Process / transport
Node host Studio giữ writer lock OS và serial queue theo project. Python CLI là client hoặc khởi động host bằng launcher được cấu hình; không dùng embedded second Node writer. Converter/renderer subprocess nhận snapshot+allowlisted arguments. Nếu host chưa chạy, lệnh inspect có thể đọc committed manifest nhưng mutation yêu cầu launcher/broker, không tự sửa file.

Broker bind127.0.0.1, token/session, Host/Origin kiểm tra; runtime info lưu user-local không vào project export/Site. UI/CLI/MCP giữ đích đầu ra phía client và chỉ gửi UUID opaque; broker không nhận đường dẫn ổ đĩa, không ghi vào đích người dùng. Renderer lưu tối đa 10 job gần nhất trong `.jobs`, chỉ một job hoạt động tại một thời điểm, với revision/source SHA và tiến độ theo frame/camera. File route chỉ đọc file đã hoàn tất, kiểm tên, SHA-256 và byte length.

MCP tools dùng command schema JSON, requestId/projectId/expectedRevision; hỗ trợ protocol `2026-07-28` trên stdio và chỉ công bố command đã nối. MCP host phải duyệt mutation; gọi tool không cấp quyền ghi game hoặc đăng Site. Topview source baseSequence cho phép base cũ trong một số ops; shared expectedRevision là exact CAS riêng, không sửa semantics legacy CLI.

## Retry / lỗi / history
Duplicate ID cùng payload trả cùng result kể cả restart; khác payload409. Timeout=>query requestId trước retry. Job chạy quá lâu có cancel; trước commit không đổi project, sau commit trả committed và dùng Undo. Token hết hạn refresh session, không retry mutation bằng ID mới. Writer busy trả423/read-only. Job bake tính từ revisionr nhưng attach lúcr+1 phải conflict/revalidate.

Dry-run trả validation/plan/loss, không revision/file writes. Batch validate trên clone, một item sai rollback cả batch. Commands từ CLI tạo history như UI; Undo/Redo sau đổi workspace và restart giữ native blob references.
