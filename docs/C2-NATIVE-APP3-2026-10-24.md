# C2 — native character editing in App 3

App 3 shot packages compose the selected character's own textured base with its owned native Action. Hero and Đen retain 20 joints; Gỗ Xưa retains 84, including the native jaw. Saved Actions reopen against that same model. Native topology/rest fingerprints reject a different model; manifest acceptance for a custom skeleton is restricted to the validated native-result path.

Save writes a durable edited library version and its native BOBJ sidecars before recording the shot draft. Return reuses the saved package when the editor is clean, keeping its Action UUID in the scene binding. Each intentional save creates another version even for identical GLB bytes. Explicit Action UUID retries require matching owner, variant chain, ancestor, rig, GLB and generated BOBJ content. Existing GLB-only library/MCP saves still generate their own sidecar; a supplied sidecar must match the trusted bake.

Native BOBJ output appends to the unchanged authoritative base. Baking uses native clip locals directly: faceForward changes the static rest view, not the existing animation's Root turn. Accessor type, count, stride, bounds and finite values are checked before allocating animation arrays.

F1 #84's Blocking / Tinh chỉnh / Xuất source is included in the coherent 1.33.0 runtime. Baseline parity is 434/434 IDs with no unresolved lookups. The C1 repeat-save deletion is included. Remaining C1 readiness/navigation changes and C7 are integrated by the parent.
